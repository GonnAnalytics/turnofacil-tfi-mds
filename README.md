# TurnoFácil

## Descripción del proyecto

TurnoFácil es una plataforma web destinada a facilitar la gestión de turnos de profesionales independientes. Busca centralizar las reservas y reducir los problemas asociados al uso de WhatsApp, llamadas y agendas físicas.

## Objetivo

Diseñar una solución que permita a los clientes solicitar y consultar turnos, a los profesionales administrar su disponibilidad y a los administradores supervisar la actividad del sistema.

## Alcance

El proyecto contempla tres roles principales:

- **Cliente:** registrarse, iniciar sesión, consultar profesionales, solicitar y cancelar turnos.
- **Profesional:** gestionar disponibilidad, consultar agenda y confirmar o cancelar reservas.
- **Administrador:** gestionar usuarios, consultar la bitácora y generar reportes.

## Tecnologías y herramientas
